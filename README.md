# DashMtGMain

Витрина на один экран. Данные собирает `collect.py` по расписанию,
страница `index.html` просто показывает `data.json`.

## Как это устроено

- `config.json` — список блоков (что показывать и откуда). Главный файл для правок.
- `collect.py` — сборщик: для каждого блока вызывает обработчик по полю `type`.
- `index.html` — страница: сетка 3 колонки × 12 строк, место блока задаётся в CSS по его `id`.
- `.github/workflows/main.yml` — расписание: каждый час и в 11:40 по Москве, плюс при любом изменении файлов и вручную.

## Добавить блок

В `config.json` в список `cards` добавь объект с полями `id`, `title`, `type` и параметрами типа.
Несколько блоков в одной карточке: `"type": "group"` и список `sections`.
Иконка-ссылка: поле `link` у карточки или блока.

Типы блоков сейчас:

| type | что делает | параметры |
|---|---|---|
| `quotes` | курсы ЦБ к рублю и BTC/USD; по клику на котировку — график, в заголовке переключатель «Неделя / Сутки». Неделя — курс ЦБ по дням (BTC — CoinGecko), сутки — рыночный курс с шагом `step` минут (Yahoo Finance, BTC — CoinGecko). Справа от пары — изменение в % за выбранный период; цвет по модулю изменения в %: неделя до 3% зелёный, до 5% жёлтый, дальше красный; сутки — 0,5% и 1% (пороги в `DELTA_ZONES` в index.html) | `fiat` (коды валют ЦБ, по умолчанию USD, EUR), `chart` (`days`, `codes`: USD, EUR, BTC, `step` — шаг суточного графика в минутах, по умолчанию 15) |
| `sheet_payments` | платежи из опубликованного листа Google Таблицы: столбцы A–C (кто, сумма, реквизит); сумма с плюсом зелёная, с минусом красная. Ссылка на CSV листа — в секрете, его имя в `secret` | `secret` |
| `sheet_list` | список: непустые ячейки одного столбца того же листа | `secret`, `col` (буква столбца), `count` (сколько строк сверху, по умолчанию 5) |
| `static` | текст из config.json (заготовка блока) | `lines` |
| `mtg_roadmap` | основные сеты Magic до конца года, без даты — TBA (Scryfall) | `count` (сколько ближайших показать; без него — до конца года), `extra` (названия сетов без даты вручную), `types` (по умолчанию core, expansion) |
| `mtg_bans` | дата следующего анонса банов (из последнего анонса Wizards) | `manual` (запасной вариант: `{"next": "…"}`) |

Для редких данных: `refresh_days` — сколько дней держать прошлый результат без запроса,
`rev` — поменяй число, чтобы сбросить кеш и собрать заново.

## Убрать блок

Добавь в его объект `"enabled": false` (или удали объект целиком).

## Если блок показывает ошибку

На странице под блоком будет пометка ⚠ и последние удачные данные.
Подробности в GitHub: вкладка Actions → последний запуск → шаг «Собрать данные».

## Пароль

Сайт открывается по паролю: `collect.py` шифрует `data.json` паролем из секрета `DASH_PASSWORD`,
страница спрашивает пароль и расшифровывает данные в браузере («запомнить на этом устройстве» — больше не спросит).
Сменил секрет — сменился пароль, сохранённые входы сбросятся. Без секрета `data.json` уходит открытым (в логе Actions будет предупреждение).

## Ключи и личные данные

Всё лежит в секретах репозитория (Settings > Secrets and variables > Actions) и передаётся в `env` шага «Собрать данные» в `main.yml`:

| секрет | что это |
|---|---|
| `DASH_PASSWORD` | пароль сайта |
| `USERS_CSV_URL` | опубликованный лист файла Users в формате CSV (Файл > Поделиться > Опубликовать в интернете > лист > CSV) |
| `USERS_SHEET_URL` | ссылка на сам файл Users (иконка «Люди») |
| `PAY_SOL`, `PAY_NASTYA` | тексты кнопок Sol и Настя |

В `config.json` личное не пишется: вместо значения ставится `"$ИМЯ_СЕКРЕТА"`, `collect.py` подставляет секрет при сборке.
Для каждого нового файла свой секрет `<ФАЙЛ>_CSV_URL`, имя указывается в поле `secret` блока.
